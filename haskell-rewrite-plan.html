Haskell Rewrite Plan

AlgoRoute backend · Servant + Nix + AWS Lambda

The existing Go backend (~1,933 lines across 7 packages) will be rewritten in Haskell. You have a C# background. The new backend must serve the same three HTTP endpoints, run the same Dijkstra/A* algorithms, and deploy to AWS Lambda via Nix-built static binaries.

Phase 1 — Nix Environment Setup

1.1 Create flake.nix

{
  inputs = {
    nixpkgs.url     = "github:NixOS/nixpkgs/nixpkgs-unstable";
    flake-utils.url = "github:numtide/flake-utils";
  };

  outputs = { self, nixpkgs, flake-utils }:
    flake-utils.lib.eachDefaultSystem (system:
      let
        pkgs        = nixpkgs.legacyPackages.${system};
        hsPkgs      = pkgs.haskellPackages;

        # Normal build (for local running)
        backend = hsPkgs.callCabal2nix "backend-hs" ./backend-hs {};

        # Static build (for Lambda — links against musl)
        staticBackend = pkgs.pkgsStatic.haskellPackages
                          .callCabal2nix "backend-hs" ./backend-hs {};

        # Lambda zip: a single `bootstrap` binary in a zip file
        lambdaZip = pkgs.runCommand "lambda.zip" {} ''
          cp ${staticBackend}/bin/backend-hs bootstrap
          ${pkgs.zip}/bin/zip $out bootstrap
        '';
      in {
        devShells.default = pkgs.mkShell {
          packages = with hsPkgs; [
            ghc cabal-install
            haskell-language-server
            hlint fourmolu
          ];
        };
        packages.default = backend;
        packages.lambda  = lambdaZip;
      }
    );
}

1.2 Enable Nix flakes (one-time)

Add to /etc/nix/nix.conf:

experimental-features = nix-command flakes

1.3 Enter dev shell

nix develop ./backend-hs    # gives GHC + cabal + HLS

Phase 3 — Data Types No IO · Start here

Start with types — they have no dependencies and force you to understand the domain before writing any logic.

3.1 Graph.hs

type NodeID = Int64

3.2 Overpass/Types.hs

Replace Go's string-tagged Element with a proper sum type (C# discriminated union):

data Element
  = NodeElement { elemId   :: Int64
                , elemLat  :: Double
                , elemLon  :: Double
                , elemTags :: Map Text Text }
  | WayElement  { elemId      :: Int64
                , elemNodeIds :: [Int64]
                , elemTags    :: Map Text Text }

3.3 API/Types.hs — Servant API type

The entire API surface is declared as a single type. Servant uses this to generate both the server routing and (optionally) a typed client.

type API =
       "api" :> "route"
         :> ReqBody '[JSON] RouteRequest
         :> Post    '[JSON] RouteResponse
  :<|> "api" :> "suggest"
         :> QueryParam "q" Text
         :> Get     '[JSON] [SuggestResult]
  :<|> "api" :> "reverse"
         :> QueryParam "lat" Double
         :> QueryParam "lon" Double
         :> Get     '[JSON] ReverseResponse

-- JSON shapes matching the existing API exactly:
data RouteRequest    = RouteRequest    { origin, destination, algorithm :: Text }
data RouteResponse   = RouteResponse   { algorithm       :: Text
                                       , distanceMeters  :: Double
                                       , path            :: [PathNode]
                                       , visitedNodes    :: [CoordJSON]
                                       , originCoord     :: CoordJSON
                                       , destinationCoord:: CoordJSON }
data PathNode        = PathNode        { nodeId :: Int64, lat, lon :: Double }
data CoordJSON       = CoordJSON       { lat, lon :: Double }
data SuggestResult   = SuggestResult   { displayName :: Text, lat, lon :: Double }
data ReverseResponse = ReverseResponse { address :: Text }

-- Derive (ToJSON, FromJSON) for all via `deriving (Generic)` + aeson field options

Phase 4 — Pure Algorithms No IO

4.1 Routefinding/Heap.hs

Port the indexed min-heap. Public interface:

data IndexedHeap
empty       :: IndexedHeap
insert      :: NodeID -> Double -> IndexedHeap -> IndexedHeap
popMin      :: IndexedHeap -> Maybe ((NodeID, Double), IndexedHeap)
decreaseKey :: NodeID -> Double -> IndexedHeap -> IndexedHeap
member      :: NodeID -> IndexedHeap -> Bool

Internally: (Seq Entry, Map NodeID Int) mirroring the Go []ipqEntry + map[NodeID]int.

4.2 Routefinding/Dijkstra.hs

The Go while-loop becomes a tail-recursive helper — think of it as a while that returns a value instead of mutating:

dijkstra :: Network -> NodeID -> NodeID -> Either RouteError RouteResult
dijkstra net start goal = go initialHeap initialCosts Map.empty []
  where
    go heap costs parents visited
      | isEmpty heap    = Left NoPathFound
      | current == goal = Right (buildResult costs parents visited)
      | otherwise       = go heap' costs' parents' (current : visited)
      where
        Just ((current, _), heap') = popMin heap
        -- relax edges: for each neighbour, update costs and parents if shorter path found

4.3 Routefinding/AStar.hs

Identical structure to Dijkstra. Only difference: priority = g + haversine current goal.

4.4 Mapping.hs

The Go nested loop becomes a foldl over ways — each way folds over its consecutive node pairs:

buildNetwork :: BuildOptions -> [Element] -> Map Int64 Element -> Network
buildNetwork opts ways nodeById = foldl addWay emptyNetwork ways
  where
    addWay net way = foldl (addEdgePair opts nodeById way) net (consecutivePairs way)

Phase 5 — External APIs IO

5.1 Shared HTTP client (Env record)

Create one Manager at startup and thread it through the app. Think of it like a scoped singleton in C#:

data Env = Env
  { httpManager  :: Manager
  , networkCache :: Cache
  }

newEnv :: IO Env
newEnv = Env
  <$> newManager tlsManagerSettings
  <*> newCache

5.2 Nominatim wrappers

Three modules (Geo/Geocode.hs, Geo/Suggest.hs, Geo/Reverse.hs), all following the same pattern:

-- ExceptT GeoError IO a  ≈  async Task<a> that can throw GeoError
geocode :: Manager -> Text -> ExceptT GeoError IO Coord
Nominatim returns lat/lon as JSON strings, not numbers. Use read @Double . unpack to convert — same as the Go code's strconv.ParseFloat.

5.3 Overpass/Client.hs

fetchFromAPI :: Manager -> BBox -> ExceptT OverpassError IO Response
buildQuery   :: BBox -> Text    -- the Overpass QL string

Set 30-second timeout on manager settings. Use http-client's response body reader with a 10 MB cap.

Phase 6 — Services Layer IO + Concurrency

6.1 Services/Cache.hs — TVar

Use STM/TVar instead of Go's sync.RWMutex. Think of it like C#'s ConcurrentDictionary, but transactional — atomically guarantees all-or-nothing, no manual lock/unlock:

newtype Cache = Cache (TVar (Map BBox Response))

newCache    :: IO Cache
lookupCache :: Cache -> BBox -> IO (Maybe Response)
insertCache :: Cache -> BBox -> Response -> IO ()

6.2 Services/Routing.hs — orchestration pipeline

The 7-step Go pipeline maps cleanly to monadic do-notation. ExceptT short-circuits on the first failure, exactly like throwing an exception:

-- ExceptT AppError IO  ≈  async Task with typed errors
type Pipeline a = ExceptT AppError IO a

routeByAddress :: Env -> AddressRouteRequest -> Pipeline AddressRouteResult
routeByAddress env req = do
  originCoord <- geocode (httpManager env) (origin req)
  destCoord   <- geocode (httpManager env) (destination req)
  let bbox     = paddedBBox originCoord destCoord
  when (bboxAreaKm2 bbox > 500) (throwError AreaTooLarge)
  response    <- fetchOrCache env bbox
  network     <- liftEither (buildNetwork (mapOpts req) response)
  startNode   <- snapToNetwork network originCoord
  goalNode    <- snapToNetwork network destCoord
  result      <- liftEither (runRouter (algorithm req) network startNode goalNode)
  return (enrichResult result originCoord destCoord network)

liftEither converts Either to ExceptT — analogous to if (x == null) throw new Exception(...) in C#.

Phase 7 — Servant Handlers HTTP

7.1 API/Handlers.hs

The server function wires together all handlers. The :<|> combinator matches Servant's API type:

server :: Env -> Server API
server env = handleRoute env
        :<|> handleSuggest env
        :<|> handleReverse env

handleRoute :: Env -> RouteRequest -> Handler RouteResponse
handleRoute env req = do
  result <- liftIO $ runExceptT (routeByAddress env (toServiceReq req))
  case result of
    Left e  -> throwError (toServantError e)   -- 400 or 500
    Right r -> return (toRouteResponse r)

Servant's Handler is already ExceptT ServerError IO, so the error plumbing slots in cleanly.

7.2 CORS middleware

Add wai-cors; wrap the Application before handing to Warp or Lambda:

corsApp :: Application -> Application
corsApp = cors (const $ Just simpleCorsResourcePolicy
  { corsOrigins        = Nothing         -- allow all
  , corsMethods        = ["GET","POST","OPTIONS"]
  , corsRequestHeaders = ["Content-Type"]
  })

Phase 8 — Entry Points Wiring

8.1 Local Warp server

main :: IO ()
main = do
  opts <- execParser cliParser       -- optparse-applicative
  env  <- newEnv
  run (port opts) (corsApp (serve (Proxy @API) (server env)))

8.2 Lambda entry point (compiled with -DLAMBDA)

wai-handler-hal converts any WAI Application into a Lambda custom runtime handler. The HAL runtime handles the event loop — your code just provides the app:

#ifdef LAMBDA
import Network.Wai.Handler.Lambda (run)

main :: IO ()
main = do
  env <- newEnv
  run (corsApp (serve (Proxy @API) (server env)))
#endif

Lambda invokes the binary named bootstrap, which calls main, and HAL takes it from there.

9.3 Cold starts

The static binary is ~15 MB. Typical cold start: 200–400 ms. Add a scheduled EventBridge ping if you need consistent latency.

9.4 In-memory cache on Lambda

Lambda instances are reused between invocations. The TVar cache persists between calls on the same instance — identical to the Go behavior. No Redis needed.

Recommended Port Order

  1. Graph.hs + Routefinding/ — pure, no IO; verify algorithms pass tests first
  2. Overpass/Types.hs — get JSON parsing right using the existing fixture file
  3. Geo/ + Overpass/Client.hs — introduce IO; test against live APIs
  4. Mapping.hs — transform types; test with fixture
  5. Services/ — orchestration pipeline and TVar cache
  6. API/ — Servant type definition, handlers, CORS
  7. Main.hs — local Warp entry first, then Lambda entry
  8. flake.nix Lambda build — static binary + zip packaging
